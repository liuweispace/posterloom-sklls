
# Visual Benchmark

Engineering tests prove that routing, prompt composition, schemas, and compatibility logic execute. They do **not** prove every image-generation backend will produce beautiful results.

Score each actual generated poster from **0 to 2** on each axis:

1. Identity preservation
2. Composition
3. Lighting
4. Palette
5. Material behavior
6. Edge treatment
7. Typography
8. Source specificity
9. Style specificity
10. Anti-slop quality

## Threshold
- **17–20:** pass
- **14–16:** revise
- **0–13:** reject and re-route/recompose

A routing regression pass is not a visual benchmark pass. Keep these claims separate in public documentation.
