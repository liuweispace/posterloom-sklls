
# Composition

## Default
- One finished poster per source image.
- Default ratio: **3:4 vertical**.
- Image remains dominant.
- PosterLoom may crop, simplify, enlarge, reduce, shift, extend quiet background, or remove nonessential clutter when identity remains intact.

## Hierarchy
Every poster should have:
1. one hero anchor;
2. one supporting spatial system;
3. one quiet zone;
4. optional restrained typography.

## Hard batch rule
For N source images:

`N sources -> N scene maps -> N style decisions -> N prompts -> N independent posters`

Never merge separate source images into:
- a collage;
- contact sheet;
- moodboard;
- scrapbook;
- album;
- multi-panel poster;
unless the user explicitly asks for that format.

## Crop protection
Never crop through:
- a face or key hand gesture;
- an identity-defining roof/tower silhouette;
- the defining contour of a product/object;
- culturally meaningful text the user asked to preserve.

## Canvas extension
Canvas extension is allowed only to create natural breathing room. It must preserve perspective, light, material, and source logic.
