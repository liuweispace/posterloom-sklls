
# Originality and Scope

PosterLoom is an independently authored, source-led photo-to-poster workflow built around the open Agent Skills format.

Its distinctive combination is:
- structured scene analysis;
- 29 direct visual systems;
- one constrained hybrid meta-style;
- adaptive routing;
- identity-first transformation;
- restrained typography;
- anti-slop QA;
- deterministic helper scripts;
- explicit separation between engineering validation and visual benchmarking.

Generic media/design terms such as watercolor, risograph, Swiss grid, lithograph, gouache, or screenprint describe established visual approaches and are not proprietary style names.

No third-party prompt text is required at runtime. Before commercial branding or trademark use, maintainers should perform their own name/trademark review. The MIT license covers this repository's code and authored content, not third-party marks.
